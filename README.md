# Presentations

Collection of the presentations I gave on various occasions and topics.

## Included Presentations

- [How I learned to stop worrying and love generics in Go](./go-meetup-govy/)  
  A Go meetup talk about runtime validation APIs,
  moving from simple checks and reflection to type-safe generics,
  and the rationale behind [govy](https://github.com/nobl9/govy).

- [What the heck is MCP?](./what-the-heck-is-mcp/)  
  An introduction to the Model Context Protocol:
  why LLM applications need shared integrations,
  how hosts, clients, and servers interact,
  and what MCP tools, resources, prompts, and protocol features provide.
